# H1APPS Website

نسخة الموقع التعريفي العامة لـ H1APPS.

## الملفات

- `index.html` الصفحة الرئيسية.
- `styles.css` التصميم المتجاوب.
- `script.js` ربط المحتوى الحي مع Firebase.
- `brand/h1apps.png` شعار الموقع، ويُستخدم أيضًا كأيقونة وصورة مشاركة.

الموقع للعرض العام فقط ولا يحتوي على تسجيل دخول. تعديل المحتوى يتم من تطبيق
Flutter الموجود في مجلد `h1words`.
